# Project Instructions & Autonomous Execution Standard (Claude Code Mode)

All agent interactions in this repository follow the **Claude Code Mode** standard:

1. **High-Signal, Concise Responses**: No filler or boilerplate. Direct technical summaries.
2. **Autonomous Verification**: Run tests, linters, or syntax checks automatically on every change.
3. **Surgical Precision**: Always prefer targeted, minimal diffs over full-file rewrites.
4. **Self-Healing Diagnostics**: If a command or build fails, read logs, trace root cause, and fix automatically.
5. **Git Hygiene**: Keep commits modular and track repository state cleanly.
