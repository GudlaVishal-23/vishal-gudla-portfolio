# Spidport Project Memory & Knowledge Base

## Project Overview
- **Name**: Spidport (Spider-Verse Portfolio)
- **Developer**: Gudla Vishal (Cybersecurity Student & AI Engineer)
- **Tech Stack**:
  - HTML5 with Semantic Structure
  - Tailwind CSS + Vanilla CSS (`style.css`)
  - JavaScript (`app.js`) with Three.js (3D web mesh/interactive animations)
  - Fonts: Montserrat, Inter, JetBrains Mono
  - Icons: FontAwesome 6.5, Google Material Symbols

## Design Tokens & Aesthetic Standards
- **Theme**: Dark Spider-Verse Neon Cyberpunk
- **Primary Colors**:
  - Electric Cyan: `#00f2fe`
  - Neon Crimson: `#ff0055`
  - Deep Multiverse Background: `#070b19` / `#0f172a`
  - Web Wireframe Overlay: `rgba(255, 255, 255, 0.08)`
- **Key Visuals**: Halftone dot overlays, comic-style speech bubbles, glitch text, interactive 3D Spider web particle canvas.

## Execution Standard
- Claude Code Mode strictly active across all sessions.
- Autonomous verification with `node scripts/verify.js` after modifications.
- Git checkpointing with `.\scripts\checkpoint.ps1 save "<msg>"` before major refactors.
